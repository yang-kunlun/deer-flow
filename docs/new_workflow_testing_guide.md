# 新工作流程测试指南

## 🎯 测试目标

本指南将帮助您体验DeerFlow新集成的specialized agent功能，包括智能质量控制、步骤协调管理、协作管理系统等。

## 🚀 服务状态

✅ **后端服务**：http://localhost:5000
✅ **前端服务**：http://localhost:3000
✅ **模型配置**：Claude sonnet 4 (通过OpenRouter API)

## 🔧 新功能概览

### 1. 智能质量控制系统
- **data_validator**: 自动验证搜索结果质量
- **quality_scorer**: 对搜索结果进行0-10评分
- **优先级过滤**: 优先使用7.0分以上的结果

### 2. 步骤协调管理
- **step_coordinator**: 分析步骤依赖关系
- **智能调度**: 优化执行顺序和并行处理
- **错误处理**: 自动重试和故障恢复

### 3. 协作管理系统
- **collaboration_manager**: 动态agent分配
- **协作模式**: 支持顺序、并行、层次、对等协作
- **性能监控**: 实时协作效率跟踪

### 4. 上下文管理优化
- **context_manager**: 分步上下文控制
- **智能摘要**: 自动生成步骤摘要
- **长度优化**: 防止上下文溢出

### 5. 权威源优先搜索
- **authority_search**: 优先政府和官方数据源
- **可信度评估**: 多维度来源可信度分析
- **权威标识**: 自动标记权威来源
